OpenKB is an open-source knowledge base: a Drupal 11 backend with a decoupled
Nuxt frontend, real-time collaborative editing (Hocuspocus/Yjs), spaces with
page trees, and an optional AI chat with semantic search over your content.

This package runs the complete upstream stack in one app: the Nuxt frontend
on the main domain, Drupal on a second domain, MySQL from Cloudron, and a
bundled single-node OpenSearch for search and vector retrieval.
